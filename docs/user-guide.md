# 使用指南

安装、启动和 API 配置见[项目说明](../README.md)。打开 [工作台](http://127.0.0.1:5173)，先选择或新建课程。

## 资料与图谱

1. 上传 DOCX、文本 PDF、TXT 或 Markdown，单文件最多 20 MB，PDF 最多 100 页。检查解析警告、章节和原文；扫描件及图片内容需要人工处理。
2. 从原文建立知识点，核对名称、别名、定义和来源后确认；按需建立并审核关系，先修关系不允许成环。
3. 点击节点查看依据和相关提问。图谱内输入问题可匹配并定位，虚线表示模型建议，实线表示人工确认；调整关联可选择零个或多个节点，原始预测保留。
4. 资料换版使用“更新版本”。旧原件保留，受影响的教学内容需要重新审核。

本机已有《NLP知识体系》原件时，可显式导入配套课程与手工草稿：

```powershell
.\.venv\Scripts\python.exe -m ta_backend.import_curriculum docs/NLP知识体系.docx
```

其他课程资料使用上传功能；专用导入脚本包含预置节点。新克隆不含本机课程数据库和教材。

## 答疑与出题

- **答疑**：输入问题 → 查找依据 → 核查知识点和引用 → 手写或生成正文 → 保存并审核 → 导出 Markdown。查看原文在同页展开；可进入图谱核查关联。
- **出题**：新建题组 → 选 1–5 个已确认具体知识点 → 设置题型、难度和数量 → 查找依据 → 编写或生成 → 逐题核查并审核。每组最多 5 题；单选题为四个不同选项，答案 A–D。
- 资料不足时补充来源或明确缺口。生成内容需要教师核对，修改正文、引用或关联后重新审核。

## 课堂讲义

1. 新建备课，填写目标、重点问题、课前准备；选择知识点并查找依据，先补足“目标依据检查”中的缺口。
2. 编排导入、讲解、练习、总结，设置各段知识点和用时；总课时 5–240 分钟，各段用时之和须一致，最多 24 段。
3. 每段填写实际讲解、教师引导、学生任务、参考回答、检查反馈；全课补齐例题、易错点和课后巩固，可关联已审核题组。
4. 自动生成前先确认课堂安排。“生成空白环节”逐段保存，失败或停止后可继续；“只重写本环节”替换当前段并保留历史，调整安排后重新确认。
5. 阅读预览并核对篇幅、时长、互动和引用，保存、审核后导出 Markdown、Word，或通过浏览器打印保存 PDF。

教师版包含引导与答案；学生版隐藏独立答案、反馈和易错提示，课后任务使用单独的不含答案字段。讲解正文中的示范推导仍保留，发放前检查学生版预览。关联题组改动或失效后，重新选择有效题组并审核讲义。

旧提纲可继续编辑，按页面操作补充为完整讲义。常见 Word 公式和插图可在新上传资料中查看；旧资料需要换版后重新解析。公式可用 `$...$` 或独立行的 `$$...$$` 书写。

## 提问、覆盖与实验

| 页面 | 操作与口径 |
| --- | --- |
| 提问热点 | 每行一问，一次最多 50 条；可命名并切换批次，按本批次或最近 100 条统计，区分预测与人工确认 |
| 知识点覆盖 | 统计已确认具体节点的有效资料、已审核题组和讲义；从缺口跳转补题或备课，覆盖率不代表掌握程度 |
| 实验 → 模型匹配 | 同问题比较名称、TF-IDF、句向量和 MLP，查看训练曲线与开发指标；实验输入不写入课堂提问 |
| 实验 → 证据检索 | 选定目标和每组 1–10 段预算，保存普通与一跳增强结果，核查补入、移出和路径，填写相关性及改善／噪声案例，可恢复历史或导出 JSON |

自动匹配当前优先 TF-IDF；句向量和 MLP 需要本地权重，且限定冻结课程图谱。分数用于关联排序，开发标签及检索效果仍需独立人工评价。

新批次自动提出 TF-IDF 词面相似组。逐组确认是否为同一诉求，可整理成员、合并所选组，或将未归组问题手动建组。移出后不足两问的组自动解散，所有原问题保留；修改成员后重新确认。分组确认与知识点确认分开，热点按不同问题 ID 计数。点击组内问题进入单问核查和答疑，当前尚无问题组统一答复。

## 保存与常见问题

数据库和上传原件在 `data/runtime/`，模型在 `artifacts/`。备份时停止后端，一并保存数据库、上传目录和本机配置。更新代码后安装锁定依赖、执行 Alembic 升级并重启；命令见[项目说明](../README.md)。

| 问题 | 处理 |
| --- | --- |
| 页面打不开／接口失败 | 确认前后端终端运行、端口正确，后端已完成依赖安装和数据库迁移 |
| 无法生成 | 检查后端 API 配置并重启，先查找依据并补齐页面必填项 |
| 生成失败或超时 | 查看具体错误，检查服务兼容性、额度或网络，重试当前段或手工编辑 |
| 审核或导出失败 | 补齐正文、具体项关联和有效引用；资料、题组或内容改动后重新审核 |
| 本地模型不可用 | 检查权重与依赖及课程范围；清空 `TA_MATCHER_RUN_DIR` 可使用轻量词面方法 |

当前审核人由操作者填写，课程成员登录与权限尚未实现；服务默认只绑定本机。
