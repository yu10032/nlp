# 完整讲义的分段编写与成品输出

实施日期：2026-10-29。按用户要求深化讲义生成、资料依据和预览导出；不调用用户的生成 API，不添加通用任务平台、多代理流程或重复校验层。

## 当前可用流程

1. 选择知识点，编排导入、讲解、练习、总结的标题、用时与知识点分配，保存并确认课堂安排。
2. 逐个空白环节调用生成器，完成一段即保存一份修订。可停止后续环节；模拟超时后已完成内容保持，重新打开后可继续。
3. 对某段填写修订要求，单独重写和保存；其他段落与教师填写的准备、作业保留。修改安排后重新确认，所有内容修改仍使原审核失效。
4. 图增强检索先为每个目标分配直接依据，界面列出目标依据检查。缺少有效直接来源时阻止该段生成，并明确指出需要补充的知识点。
5. 新上传 Word 提取常见 Office Math 为 LaTeX，保留原文插图引用；原文预览可排版公式、显示同课程插图。不识别图片中的知识，无法完整提取的公式提示回看原件。
6. 阅读预览包含目录跳转、详细正文、活动、答案、题组快照及来源。审核后导出 Markdown、可编辑公式的 Word，或通过浏览器打印保存 PDF；打印前重新核查审核、引用及版本。
7. 教师版与学生版分别预览、导出 Word 和打印 PDF。学生版隐藏教师提示和独立答案字段，题组使用结构化题干/选项，课后任务使用单独的无答案字段；不会从混合文本猜测并删除答案。讲解正文中的示范推导保留，发放前由教师核对。

## 维护边界

- 环节 id、安排确认状态保存在已有 JSON 正文，继续使用原修订与审核表；无新数据库表或迁移。
- 路由处理课程、版本和审核语义；生成器只校验本次外部响应的结构、安排一致性、引用范围和内容展开程度。生成期间结束读取事务，返回后重读版本，避免覆盖并行修改。
- 只有当前段会被替换，不批量重写已有正文；错误不返回空内容，不自动重试或切换到假模型。
- 后端新增 latex2mathml、mathml2omml，用于 Word 可编辑公式；前端新增 Markdown 和 KaTeX 本地排版依赖。部署后端不依赖桌面 Word 或 LibreOffice；PDF 由用户浏览器打印。
- 旧资料不自动重新解析，旧提纲不自动升级。需要利用新解析功能时上传替换版本；需要分段生成时补齐并确认安排。

## 验证记录

业务测试覆盖分段失败和继续、单段替换、教师内容保留、安排变动后失效、生成期间的并行编辑、课程隔离、检索直接依据分配、生成输出的引用/篇幅/安排/互动检查，以及 Word 公式、表格、插图与审核导出边界。使用 `scripts/check.ps1` 运行完整检查；默认 HTTPX 生成网络传输被测试夹具禁止，适配器只用 MockTransport。

浏览器使用隔离 SQLite、手工教学样例及显式离线生成器验证确认安排、停止、模拟超时、刷新后继续、局部重写、审核、Word 下载、打印前重查、公式预览和 390px 布局，记录无页面异常和外部请求。验收文件放在忽略的 `tmp/lesson-flow-qa/`；未写入用户课程数据库。

实际下载的 Word 用隐藏的 Word 2021 转为 PDF，浏览器 PDF 用 Chromium 打印，均为九页排版测试样例；逐页渲染检查中文、公式、引用与分页。检查后修正了 Word 默认标题横线和主题字体覆盖、浏览器打印续页底色。桌面 Word 只用于本次验收，不作为应用运行依赖。

学生版另行检查教师答案标记不可见、无答案任务保留，以及 Word/PDF 输出与手机预览；正式检查当前通过 56 项业务测试，并通过 Ruff、前端类型检查和构建。

离线样例用于流程与排版验证，不代表模型生成、课程教学内容或真实长讲义质量已验收。自训模型、语义检索、扫描件 OCR、图片内容识别、课程成员权限仍未因此接入。
