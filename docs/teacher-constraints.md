# 课程规则与本阶段决定

记录日期：2026-10-28。

| 项目 | 当前决定或事实 | 依据 |
| --- | --- | --- |
| 在线生成 API | 允许使用 | 用户在本次对话中明确答复“已允许在线生成 API” |
| 提供者与密钥 | 待用户在后端 `.env` 配置 | 本次未提供具体服务、模型或凭据 |
| 自主训练范围 | 冻结句编码器 + 自主训练 MLP 头 | 研究基线；课程对该训练形式的认定仍待书面条款 |
| 第一阶段 | D1–D2 最小链路：上传、来源、图谱、词面基线、证据、草稿、审核 | 本次实施范围 |
| 正式语料 | 待提供实际课程 DOCX / PDF | 工作区尚未发现基线提及的《NLP知识体系(1).docx》 |
| 部署路线 | 先本地闭环，提供持久化容器配置 | 本次未提供服务器；本机未发现 Docker 命令 |
| 数据校验 | 保留外部输入与关键业务约束，不建立哈希清单 | 用户在前序对话中的明确要求 |

在线服务采用兼容 `chat/completions`、JSON 输出的 HTTP 接口。配置缺失时进入显式禁用状态，不自动选择供应商或发送资料。
正式课程资料外传前需确认资料许可。当前身份仍是本地协作原型，审核人名称由操作人填写；课程成员登录与鉴权未进入本阶段公网验收。
