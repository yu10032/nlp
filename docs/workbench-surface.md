# 第一阶段工作台

Mode: Redesign。以「讲义与批注」视觉方向重构课程工作台，保留全部业务链路与课程隔离约束。
范围：资料、图谱、答疑、覆盖、实验与共享顶栏导航。

## Direction contract

THESIS: 把工作台做成一份正在批注的课程讲义；纸面承托宋体讲义页，页边旁注列出原文依据，用铅笔、墨笔、朱批和荧光区分机器建议、教师确认、审核签章与来源定位。

OWN-WORLD: 米白纸底配暖白讲义页；56px 纸色顶栏整合课程切换、三段流程导航与真实服务状态；宋体排印内容与词条，黑体负责操作与注记。

STORY: 上传资料形成章节片段，在点阵画布与词条页之间确认知识图谱，针对提问检索旁注依据并撰写答复，最后以朱批完成审核或定位覆盖缺口。

FIRST VIEWPORT: 顶端单行导航与系统状态；下方直接呈现页面标题与双栏讲义工作区（资料页左目录右讲义，图谱页左点阵画布右词条详单，答疑页左讲义编辑区右编号旁注）。窄屏按任务顺序纵向堆叠。

FORM: 去除冗余边框嵌套与装饰性说明，禁用操作以虚线边框配合明确原因呈现；点击查看原文在原位或目标讲义段用荧光标出出处。
