# 试标与问题家族

第一阶段的开发样本位于 `data/annotations/pilot-questions.jsonl`。这些问题为手工编写的开发候选，`suggested_node_ids` 不是人工金标准。
标注者在独立审阅后填写 `confirmed_node_ids` 和 `reviewer`，把 `annotation_status` 改为 `confirmed`；分歧单独记录。

## 判定规则

- 只有回答问题所必需、且问题具有明确语义联系的知识点才标正例。
- 一个问题可以关联多个节点，超出图谱的问题可以关联零个节点。
- 名称接近、同一章节或彼此相邻并不必然相关，困难负例必须核查。
- 问题没有出现知识点原名也可以相关，不能把词面基线输出当作标签。
- 考试、评分或课程通知不属于知识点，不强行挂到“自然语言处理”节点。

同一原问题的改写和全部正负样本对使用同一个 `family_id`。先划分家族，再训练与选阈值。
这些开发家族只用于试标和链路测试；正式训练数据另建版本，独立保留未用于开发的评价问题。
正式模型比较固定图谱、资料、编码器与候选预算，分开评估召回和排序。第一阶段尚未产生 B1/M1 或正式测试指标。
