# 教学工具与提问热点

实施日期：2026-10-29。按用户要求优先完成辅助出题与单次课备课，保留原研究文档作为需求依据，本页记录实施事实。

## 可用流程

选择课程“自然语言处理 · 知识体系”，进入“出题”的课程题库，打开“语言模型基础练习”；进入“备课”的已存备课，打开“统计语言模型入门”。两者初始均为手工整理、未审核草稿。

- 出题：按章节筛选并选择 1–5 个已确认知识点，设置题型、生成数量与预设难度；支持单选、简答，每组最多 5 题。逐题编辑题干、选项、参考答案、解析、知识点与原文依据。单选答案、必要字段、组内近重复题干在生成输出和审核处检查。
- 备课：输入教学目标、重点问题与 5–240 分钟课时，编辑最多 12 个环节；可增删、排序，记录讲解、活动、例子、知识点与依据。从已审核题组关联课堂练习，保存时保留题组版本与内容快照。审核前要求分段总时长与课时一致。
- 教师审核：共用草稿、修订历史、审核记录和 Markdown 导出。正文、节点、引用变更使旧审核失效；题组更新或退回，也使引用它的已审核教案失效。更新资料的原有失效机制同时覆盖题组和教案。
- 覆盖联动：知识点按具体题目、课堂环节关联聚合；选择了生成目标但尚未在内容中关联，不能通过审核或被算作覆盖。覆盖缺口可直接跳转到对应节点的出题、备课页面；图谱与提问核查也提供任务入口。
- 提问热点：一次粘贴最多 50 条原始提问，每行一条，原子保存匹配结果。查看最近 100 条，按知识点筛选，分别显示已确认关联与待确认预测数量；保留无关联确认，支持转入答疑。

当前热点是最近 100 条提问的节点频次，不是全课程累计统计、语义聚类或正式模型结果。备课的例题选择单位是已审核题组，尚未拆分为跨题组逐题组卷。

## 参考资料

原件为用户提供的 `docs/NLP知识体系.docx`。实际提取 777 段，含 9 张图片和 Word 公式；图中信息和公式需回看原件，系统不把未提取部分当作已读取。

多数章节标题使用普通段落样式，解析器 `paragraph-v2` 增加编号标题识别。原文和章节编号按原件保留，包括原件自身的重复或不一致编号；没有自动纠正教材内容。

显式导入命令：

```powershell
.\.venv\Scripts\python.exe -m ta_backend.import_curriculum docs/NLP知识体系.docx
```

导入到独立的 `nlp-curriculum` 课程，不覆盖原演示课程；该课程已存在时保留现有编辑，新版原件通过资料页替换。原件副本保存在后端存储目录。14 个节点中含 2 个章节、12 个具体知识点，来自开发时对照原文手工核对的词法分析和语言模型范围；它们不是模型自动抽取结果，也不是多人确认的正式金标准。题组与 45 分钟提纲为手工编写的教学候选，题意、难度、学情适配均待教师审核。

## 代码与维护

- 教学内容结构、完整性条件、近重复检查、Markdown 排版在 `services/teaching.py`；路由在 `api/teaching.py`，复用已有内容保存、审核与导出流程。
- 三类教学内容继续使用 `TeachingContent.body` JSON 及既有引用、关联、修订表，无新增数据库表或迁移。当前迁移仍是 `0002`。
- 在线答疑、出题、备课共用一个 HTTP 客户端方法，各业务保留自己的明确 schema。生成结果的知识点和引用限于本次目标与证据，不把资料中的文本当成可执行指令。
- 前端 `TeachingView.vue` 管理共同工作流，`QuizEditor.vue`、`LessonEditor.vue` 各自表达内容结构，`PartLinks.vue` 编辑逐项来源和知识点。原文在同页旁栏展开，避免丢失未保存内容。
- 未增加哈希核验、供应商注册平台、通用 Repository 或新的状态管理依赖。
